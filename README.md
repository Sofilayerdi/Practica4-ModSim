# Practica 4

Instalar y ejecutar:

    pip install -r requirements.txt
    streamlit run app.py

Archivos:
- `matriz.csv`: matriz de tiempos entre los 40 puntos.
- `grafo.py`: lectura de la matriz, validación de rutas, Dijkstra, A*, Hill Climbing e incidentes.
- `simulacion.py`: llegada de pedidos, cola, asignación de vehículos y experimentos.
- `app.py`: interfaz.
